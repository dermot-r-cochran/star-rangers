### Changed

- **Changelog entries are now one file per change, in `changelog.d/`** (`lib/changelog-fragments.js`, `scripts/gather-changelog.js`, `scripts/check-changelog.js`, `scripts/check-changelog-length.js`, `lib/changelog-files.js`, `test/changelog-fragments.test.js`, `changelog.d/README.md`, `CLAUDE.md`, `TECHNICAL-README.md`, 2026-11-24, Opus, Dermot's *"Yes, do that"*). Parallel sessions collided on every edit to the shared `[Unreleased]` list, so each unreleased entry is now its own small file, gathered into the release section when a release is cut. The 37 entries that stood under `[Unreleased]` moved into fragments word for word. `npm test` fails on an entry written under `[Unreleased]` or a malformed fragment; the coverage and length warnings read the fragments too.
