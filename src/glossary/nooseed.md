A **Noöseed** is a compressed mind architecture that preserves enough interior complexity to catalyse a successor universe seed-state.

It is not archival storage. A Noöseed is not a backup. It is a generative transfer structure, capable of initiating new emergence rather than merely reproducing existing content. The distinction matters, because compression that destroys generative structure produces a record, not a seed.

**Example:** A perfect memory archive of a mind, every fact and every memory losslessly recorded, is not a Noöseed if it cannot generate anything beyond what was already there. A much less complete compression that preserves the mind's capacity to form new structure under new conditions is a viable seed. The archive, however faithful, is not.
