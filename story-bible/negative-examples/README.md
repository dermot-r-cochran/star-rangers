# Negative examples

These are frames that were once filed on the site and later taken down or replaced. Each one
is kept here as a 480-pixel thumbnail with a short description of what failed, so the next
prompt, edit or critic pass can learn from it. They are not shipped. Like the rest of
`story-bible/`, the site never renders this folder.

A negative example has a fault you can name, as in Dermot's three kinds of frame: keeper,
negative example and ordinary. Each entry below says what the fault was, so the lesson is
something a check can look for, not a matter of taste.

## The century set, 10 November 2026

Dermot flagged ten filed portraits as anachronistic or wanting a redo, and set the bar:
*"They should look more like the 29th century than the 20th or 21st"*. The fix was to edit
the one or two failing objects in each frame. Where that worked, the edit replaced the
frame. Where it did not, the portrait came off its page, which is then complete without
one, and the old frame is kept here. The cause is the same throughout. A frame with a
single, small hint of the century reads as our own time whenever that hint draws as
something we already have. Generators turn a named object into today's stock version of it,
and a hint shared by several frames carries its fault into each of them.

## Lessons for the next prompt

- **A hint that draws as a stock object makes the frame anachronistic.** Before filing,
  check what the hint looks like at thumbnail size, not what the prompt calls it.
- **A shared idiom carries its fault into every frame that uses it.** If the hint copies
  another filed picture, fix that picture first: the station plate, the drone wording.
- **Edits hold when they remove or swap one object, and fail when they rebuild a
  distance.** The pier came back in every station edit.
- **One small hint is not enough when the rest of the frame is ours.** Dermot's bar is that
  a frame should look more like the 29th century than the 20th or 21st, so the setting
  itself has to carry the century, not one object in a corner of it.
